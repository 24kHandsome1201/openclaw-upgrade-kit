# Manual Routing Patterns

Use these patterns when the runtime cannot auto-select skills.

## Pattern A: Mixed -> Ops -> Coding -> Docs -> Manus
Use when runtime diagnosis leads to code changes and then doc corrections.

## Pattern B: Manus -> Research -> Docs
Use when a broad task narrows into current-source verification and then documentation correction.

## Pattern C: Manus -> Coding -> Manus
Use when a mixed task narrows into one implementation fix and then returns to broad handoff.

## Pattern D: Research -> Coding
Use when current-source analysis identifies an implementation change that should follow.

## Manual routing checklist
Before switching:
- confirm the next step truly belongs to a different lane
- confirm the dominant evidence source changed
- confirm the switch will improve execution quality
