# Synthesis Patterns

Good research synthesis should:
- separate facts from interpretation
- include source-backed conclusions
- mention meaningful uncertainty
- stay concise and decision-oriented

## Fact / inference boundary

Research outputs should explicitly distinguish:
- **Fact**: directly supported by cited sources
- **Inference**: a conclusion drawn from those facts
- **Unvalidated implication**: a likely consequence that still needs confirmation

Preferred pattern:
- Facts: "Source A states..." / "The official docs currently show..."
- Inference: "This suggests..." / "My current interpretation is..."
- Unvalidated implication: "If this rollout is complete, it would imply..." / "This likely means..., but confirmation is still needed..."

Do not collapse source-backed facts and strategic interpretation into one sentence when the difference matters.

Useful output shapes:
- comparison summary
- recommendation with tradeoffs
- differentiation analysis
- current-state verification
