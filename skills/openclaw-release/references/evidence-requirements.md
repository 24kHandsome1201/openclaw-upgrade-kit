# Evidence Requirements

A strong release-readiness pass should include evidence such as:
- clean working tree state
- current version info output
- successful packaging helper output
- successful install or archive smoke tests
- release notes aligned with actual repo contents
- benchmark/examples support for major release claims

Acceptable release deliverables include:
- release checklist pass
- dry-run report
- release notes
- release plan
- archive creation result
- version capture output

When evidence is incomplete, the final release verdict should say so explicitly.
