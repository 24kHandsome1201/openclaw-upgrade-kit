# Contributing

Thanks for contributing to `openclaw-upgrade-kit`.

## What is most helpful right now

High-value contributions include:
- new benchmark tasks
- stronger before/after examples
- clearer task patterns
- better tool-use policies
- OpenClaw integration notes
- evaluation reports comparing base vs upgraded behavior

## Contribution principles

Please keep contributions aligned with the project goals:
- improve execution behavior
- improve clarity and reusability
- prefer small focused changes
- avoid turning the repo into a prompt dump
- favor measurable improvements over stylistic rewrites

## Good contribution types

### 1. New examples
Add realistic examples that show clear behavioral differences.

### 2. Benchmarks
Add tasks that are:
- realistic
- reproducible
- easy to evaluate
- useful for comparing agent behavior

### 3. Policy improvements
Improve task decomposition, reporting structure, or tool selection guidance.

### 4. OpenClaw-specific integration notes
Document practical ways to apply these skills in real OpenClaw setups.

## Pull request guidance

When submitting a PR, include:
- what changed
- why it improves the project
- whether it affects skill behavior, examples, or evaluation
- any tradeoffs or limitations

## What to avoid

Please avoid:
- large unrelated rewrites
- copying leaked prompts verbatim into the repo
- adding marketing-heavy fluff with little practical value
- adding new files that do not improve usability, evaluation, or extensibility
