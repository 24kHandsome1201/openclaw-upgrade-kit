# Limitations

This project improves agent behavior through skills, references, examples, and evaluation patterns.

It does not by itself provide:
- a full autonomous runtime
- long-term memory/state management
- browser automation
- multi-agent orchestration
- guaranteed task success

## Important note
A Manus-like feel can be improved substantially through behavior design, but closed-product performance also depends on runtime architecture, tool surface, and orchestration quality.
