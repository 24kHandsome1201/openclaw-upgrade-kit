# Design Principles

`openclaw-upgrade-kit` is built around behavior design, not prompt mystique.

## Principles

1. Behavior over wording
2. Tools over speculation
3. Small safe steps over big vague plans
4. Validation over confidence theater
5. Deliverables over commentary
6. Extensible structure over one-file prompts

## Practical implication
A good upgrade is not the one that sounds smartest.
It is the one that makes the agent more useful in real tasks.
