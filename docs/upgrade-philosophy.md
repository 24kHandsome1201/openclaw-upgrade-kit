# Upgrade Philosophy

The purpose of this project is to upgrade OpenClaw along the dimensions users feel most directly:
- proactive planning
- evidence-first execution
- progress awareness
- concrete delivery

This project treats public system-prompt research as inspiration, not as source material to mirror verbatim.

The long-term goal is to build an open, reusable upgrade layer for execution-oriented agents.

Long-term, this also means making agent work more resumable through stage-based execution, checkpointing, and explicit recovery patterns for interrupted tasks.
