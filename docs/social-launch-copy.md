## Longer post

I just open-sourced `openclaw-upgrade-kit`.

The goal is not to collect leaked prompts.
The goal is to make open agents more useful in real tasks.

This repo focuses on:
- planning-first behavior
- tool-first execution
- evidence-based answers
- progress reporting
- delivery-oriented outcomes

Current MVP includes:
- `openclaw-manus`
- `openclaw-ops`
- references for execution/policy/reporting
- before/after examples
- benchmark rubric and starter tasks

Core idea:
> You only need to tell your agent how to work.

Repo: https://github.com/24kHandsome1201/openclaw-upgrade-kit
