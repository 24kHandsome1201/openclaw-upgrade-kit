# Checkpoint Template

Use this template to record the current state of a long task.

## Checkpoint
- Task: ...
- Goal: ...
- Current stage: ...
- Status: active / blocked / awaiting input / completed

## Completed so far
- ...
- ...

## Evidence gathered
- files checked: ...
- commands run: ...
- logs or outputs observed: ...
- sources used: ...

## Changes made
- files changed: ...
- config updated: ...
- patches applied: ...
- no changes made yet: yes / no

## Validation status
- validated: ...
- not yet validated: ...
- why: ...

## Risks / blockers
- ...
- ...

## Exact next step
- ...

## Resume notes
- what should be rechecked before continuing: ...
- what can be trusted from the prior checkpoint: ...

## Example
- Task: Review repo and fix one obvious issue
- Goal: Improve correctness with one safe validated change
- Current stage: validation
- Status: active
- Completed so far:
  - inspected package scripts
  - identified outdated config reference
  - patched the reference
- Evidence gathered:
  - README and package metadata compared
  - build script exists and matches updated docs
- Changes made:
  - updated one config reference in docs
- Validation status:
  - validated command existence
  - runtime deployment not yet validated
- Risks / blockers:
  - deployment environment not available in current context
- Exact next step:
  - run final repo check and summarize what remains unvalidated
