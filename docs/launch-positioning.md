# Launch Positioning

## Short positioning

`openclaw-upgrade-kit` is an open upgrade layer for turning OpenClaw into a more execution-oriented agent.

## One-line human message

> You only need to tell your agent how to work.

## One-line agent message

A modular skill and policy layer for making OpenClaw-style agents more planning-first, tool-first, evidence-based, and delivery-oriented.

## What makes it different

This is not a prompt archive.
It is not a leaked system-prompt mirror.
It is not trying to market itself as an official clone of a closed product.

Its value comes from:
- behavior design
- reusable execution policies
- structured skill packaging
- examples that show behavioral differences
- benchmarks that make improvement measurable

## Community value

The project is meant to help the community:
- improve open agents pragmatically
- package agent behavior as reusable skills
- benchmark execution quality instead of only language quality
- move from "interesting prompt" to "useful execution system"
