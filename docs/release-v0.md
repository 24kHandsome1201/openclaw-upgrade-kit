# Release v0 Notes

## Summary

This is the first public MVP of `openclaw-upgrade-kit`.

It introduces a first execution-oriented skill for OpenClaw and the supporting materials needed to explain, demonstrate, and evaluate the behavior upgrade.

## Included

- `openclaw-manus` skill
- execution-loop guidance
- tool-selection policy
- reporting format guidance
- task patterns for research / coding / ops / docs
- examples for expected upgraded behavior
- before/after comparisons
- benchmark rubric and starter tasks
- project positioning and limitations docs

## Why this matters

The repository is designed to move beyond prompt collecting and toward reusable open-agent behavior upgrades.

The MVP focuses on a simple but important question:

> how do we make OpenClaw feel more like an execution-oriented operator?

## Known limitations

This release does not yet provide:
- runtime orchestration
- memory/state management
- browser automation
- multi-agent coordination
- deep OpenClaw runtime integration

## Next priorities

- expand benchmark coverage
- add stronger real-world examples
- refine installation/integration guidance
- explore runtime-level upgrade patterns
